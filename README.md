# 🧑‍💻 Portfólio Pessoal

> Meu portfólio pessoal desenvolvido com React, apresentando meus projetos, habilidades e formas de contato.

---

## ✨ Funcionalidades

- 🌗 **Tema claro/escuro** com animação
- 🎮 **Skill tree** com barras de progresso animadas e sistema de ranks (S+ / S / A / B)
- 🏆 **Cards de projeto** com destaque dourado para projetos em evidência
- 🎠 **Carrossel de projetos** com navegação por setas e paginação
- 🎨 **Estética pixel art** com fonte Press Start 2P nos títulos
- 📱 **Responsivo** para mobile e desktop
- ⚡ **Animações** de entrada com Framer Motion em todas as seções

---

## 🗂️ Seções

| Seção | Descrição |
|-------|-----------|
| **Home** | Apresentação inicial |
| **Sobre Mim** | Um pouco da minha história |
| **Conhecimentos** | Skill tree com tecnologias e níveis |
| **Projetos** | Carrossel com meus projetos |
| **Contato** | Formas de entrar em contato |

---

## 🛠️ Tecnologias

- [React](https://react.dev/)
- [Vite](https://vitejs.dev/)
- [Framer Motion](https://www.framer.com/motion/)
- CSS puro com variáveis customizadas
- JavaScript (ES6+)

---

## 🚀 Como rodar localmente

```bash
# Clone o repositório
git clone https://github.com/GustavoAndradeBr/Portfolio.git
# Entre na pasta
cd portifolio

# Instale as dependências
npm install

# Rode o projeto
npm run dev
```

Acesse `http://localhost:5173` no navegador.
